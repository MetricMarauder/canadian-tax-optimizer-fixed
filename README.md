# Canadian Tax Refund Estimator (2025–2026, all provinces and territories)

> **Disclaimer**: This app is an **estimator** for educational/planning purposes. It is **not** official filing software and may not match CRA or Revenu Québec results in all cases.

## What this repo does
- Estimates the **refund or amount owing** for an individual or couple in **any province or territory**, for the **2025** and **2026** tax years (province and year selectors in the UI; `province` and `year` in the API).
- Shows **benefits paid separately** (Canada Groceries and Essentials Benefit, Canada child benefit, provincial benefits) apart from the refund.
- Optimizes household claims between spouses (donations, child care, benefits, CWB, spouse amount, tuition and disability transfers).
- Produces an **explainable breakdown** per jurisdiction and per row of the Excel catalog (`ontario_federal_tax_credits_2025.xlsx`, Federal + Ontario rows).
- All parameters live in `lib/tax/config/<year>.json`, generated by `scripts/generate-config.py` (no magic numbers in code).

## Tech stack
- Next.js + TypeScript
- API: `app/api/calculate/route.ts`
- Validation: zod

- Tests: Vitest

## How the rules engine works
### Normalized internal model
Each sheet row becomes a `RuleItem` (`lib/rules/types.ts`). The app **never hardcodes** the list of credits/deductions — it reads them from the Excel.

### 3-prong logic
- **A) Deductions**: reduce taxable income
- **B) Credits**: non-refundable (reduce payable) and refundable/benefits (increase refund / reduce owing)
- **C) Other benefits / transfers**: income-tested benefits, grants, etc.

### Mapping layer (text -> code)
Because the Excel “Eligibility” / “Calculation” are human summaries, we implement executable logic via:
- `lib/rules/mapping/rules_mapping.json`: maps **Credit/Deduction Name** → prong + required inputs + params
- `lib/rules/implemented.ts`: code implementations keyed by normalized names

If a row has **no mapping**, or is mapped but not implemented, it still appears in the **Explain my result** list with an explicit reason.

## Implemented rules

**Federal (every province)** — brackets, BPA (with phase-out), Canada employment amount, disability amount, donations, tuition (with spousal transfer), spouse amount, CPP/QPP and EI/QPIP credits, enhanced CPP/QPP deduction, eligible-dividend gross-up and credit, CWB, Canada Groceries and Essentials Benefit (formerly GST/HST credit), Canada child benefit, Quebec abatement (16.5%).

**Deductions** — RRSP (capped by the deduction limit when entered), FHSA, RPP, union dues, child care (per-child limits and 2/3 of earned income; claimed by the lower-income spouse).

**Provincial/territorial (generic engine, `lib/tax/provincial.ts`)** — brackets, basic personal amount (income-tested in Manitoba and Yukon), spouse amount, disability amount, CPP/EI credits, donations (including Alberta's 60% first-$200 rate and BC/Quebec high-income rates), dividend tax credit, Yukon's Canada employment amount, Ontario surtax, Health Premium and LIFT credit, and low-income tax reductions (ON, BC, NB, NS, PE, NL).

**Provincial benefits**

| Province | Benefits modelled |
|---|---|
| ON | CARE child care credit (on return), Ontario Trillium Benefit (sales tax credit, energy and property tax credit, Northern Ontario energy credit), Ontario child benefit |
| BC | B.C. family benefit, renter's tax credit (on return) |
| AB | Alberta child and family benefit (base + working components) |
| SK | Saskatchewan low-income tax credit |
| MB | Renters affordability tax credit (on return) |
| NB | NB harmonized sales tax credit, NB child tax benefit (with working income supplement) |
| NS | NS affordable living tax credit, NS child benefit |
| PE | Island essentials benefit, PEI child benefit |
| NL | NL income supplement, NL child benefit, NL seniors' benefit |
| YT / NT / NU | Yukon, NWT and Nunavut child benefits |
| QC | Solidarity tax credit, work premium (on return), family allowance |

**Quebec** is simplified: Quebec tax uses Quebec brackets, the basic, living-alone and donation credits, the deduction for workers and the dividend credit; QPP/QPIP and the reduced EI rate replace CPP/EI.

### Known limitations
Not modelled: self-employment, non-eligible dividends, pension income/splitting, age amount, medical expenses, provincial tuition credits, the senior version of the OEPTC, the Ontario senior homeowners' grant, Manitoba family tax benefit and child benefit, Yukon low-income family credit, Nova Scotia poverty reduction credit, the federal and Alberta "top-up" credits for very large non-refundable claims, AMT, and multiple-employer CPP/EI overpayments. Child age bands are approximate (under 7 is treated as under 6 for the CCB). Each province's `notes` (shown in the UI) list its own estimates and gaps.

## Where the numbers come from
`scripts/generate-config.py` holds every parameter, with notes on anything that is an estimate. Sources: CRA indexation and payroll tables, Finance Canada, Revenu Québec, provincial budgets and finance ministry pages, KPMG and RCGT 2025/2026 tax tables, and CRA benefit pages. `tests/provinces.test.ts` checks the 2026 Ontario, New Brunswick and Quebec parameters against published tax tables. See `docs/UPDATING_TAX_YEARS.md` for the yearly update process.

## API
`POST /api/calculate`

```json
{ "year": 2026, "province": "BC", "household": { "maritalStatus": "single" }, "taxpayer": { "age": 30, "income": { "employment": 60000 }, "deductions": {}, "credits": {}, "benefits": {} } }
```

`province` accepts a code (`BC`) or a name (`British Columbia`); `year` defaults to 2025. Request/response types are in `lib/api/types.ts`; validation is in `lib/api/schema.ts`.

## Tests
Run:

```bash
npm test
```

Included unit tests cover brackets, deduction caps, BPA phase-out, CWB, household optimization, seeded end-to-end scenarios (cross-checked against an independent calculation) and regression tests for the fixes in `tests/bugfixes_2025.test.ts`, and `tests/provinces.test.ts` (every province × both years, province-specific rules, and published 2026 tax tables).

## Extending coverage
- **Federal rules**: run `npm run print:excel`, add the row name to `lib/rules/mapping/rules_mapping.json` and an implementation in `lib/rules/implemented.ts`.
- **Provincial parameters**: edit `scripts/generate-config.py`, then `python3 scripts/generate-config.py`.
- **Provincial benefits**: add an entry to the province's `benefits` list in the generator and a calculator in `BENEFIT_CALCULATORS` (`lib/tax/provincial.ts`).
- Add tests for any new rule.
